# Luxury Arabic Restaurant Website

مطعم نثري الجهراء - A luxury RTL Arabic restaurant website

## 🌟 Features

- Fully responsive RTL (Right-to-Left) layout
- 6 connected pages: Home, Menu, About, Gallery, Contact, Reservations
- Modern glassmorphism design
- Interactive reservation system with guest slider
- Real business data integration
- Pure HTML, CSS, and JavaScript (no frameworks)

## 📱 Pages

- **Homepage** (`index.html`) - Hero section with featured dishes
- **Menu** (`menu.html`) - Complete food menu with categories
- **About** (`about.html`) - Restaurant story and values
- **Gallery** (`gallery.html`) - Photo gallery with filters
- **Contact** (`contact.html`) - Contact form and location
- **Reservations** (`reservations.html`) - Table booking system
